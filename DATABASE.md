# Database Schema Reference

## Collections
- **users**: Accounts, target exams, XP, level, streak, unlocked badges.
- **questions**: Central question bank with options, correctAnswer, explanation, subject, topic, exam, difficulty, sourceType, verified, status.
- **studyPacks**: Uploaded materials, short notes, one-liners, concepts, generated MCQs.
- **testAttempts**: Test scores, accuracy, time taken, answer breakdown.
- **mistakes**: Saved wrong questions with spaced repetition interval scheduling.
- **friendships / challenges / studyRooms**: Social and group study entities.
